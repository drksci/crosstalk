# Build log M2b (circuit tier)

## What was done
- `hw/spice/coax_rg58.lib` (generic LTRA RLC coax, L=250 nH/m, C=100 pF/m, constant R=1.8421 ohm/m = 32 dB/us at 100 MHz),
  `hw/spice/diffpair.lib` (generic NPN diff pair; NOT a vendor model), `hw/spice/unit_cell.cir` (reference netlist, regenerated by
  `circuit.write_reference_netlist()`; `cd hw/spice && ngspice -b unit_cell.cir` runs).
- `dlnn/tiers/circuit.py` (real tier, own binary raw-file reader), `dlnn/cascade.py`, `docs/circuit_extraction.md`, `tests/test_circuit.py` (8 tests).
- Extra output (not in the tier contract): `params/circuit_diagnostics.json` (other loss-compensation modes), `<outdir>/spice/*.cir|.log` (netlists, logs).

## Deviations / decisions
- ngspice 42 LTRA does not support G (`Nonzero G (except RG) line not supported`); TXL (`Y`) accepts G but has no `.ac`. Used LTRA with
  constant R, G=0 (documented in lib + omits). Consequence: low-frequency loss overstated (tap 7 DC -3.61 dB vs -2.24 dB at 100 MHz), 54-110 ps excess group delay per tap.
- Lines are cut so delay = k*d*Ts exactly (v_p = 2.00e8 m/s from L, C, not 1.98e8).
- Loss compensation: "layer" (one ideal gain trim per layer, default), "tap" (ideal per-tap repeater), "none". Headline = "layer".
- Unit cell outputs: first 8 of the layer's outputs share the input lines. NMSE = variance-normalised (stricter than energy-normalised).
- RC pool (tau = N*Ts = 1.28 us) is a leaky average, not the uniform mean; it differs from the uniform mean by NMSE 0.026 (reported in the extraction JSON).
- `inputs_from` of the C tier = `["params/circuit_extracted.json"]` (its own calibration source).
